# Git Frontend - Mission Control for Your Code

A next-generation git TUI/frontend that replaces Visual Studio for git operations. Built with epic git integration, automated workflows, and seamless Claude Code embedding.

## Vision

Replace VS Code for git-centric workflows. Not an editor—a git command center with:

- **Real branch comparison** that understands squash merges (not just commit diffs)
- **Automated commit messages** via AI
- **Native GitLab/GitHub integration** (MRs, issues, CI status)
- **Custom git implementation** for advanced comparison logic
- **Embedded Claude Code** sessions for coding tasks
- **TUI-first**, but with Electron option for GUI lovers

## Tech Stack

- **UI**: TUI (bubbletea/gum) or Electron (TBD)
- **Git**: Custom implementation + libgit2 bindings
- **AI**: Claude Code integration for commit messages, code review
- **Forge**: GitLab (`glab`) + GitHub (`gh`) CLI integration
- **Language**: Go or Rust (performance + TUI ecosystem)
